# Fiber架构

React Fiber 是 React 内部的一个重新实现的核心算法，它是从React 16版本开始引入的主要改进。Fiber架构是对React原有 reconciliation（协调）算法的重大革新，其核心目标是提高React在复杂应用中的渲染性能，尤其是优化动画效果和交互体验。

- **使用Fiber前**

  在React 16之前的版本中，是使用递归的方式处理组件树更新，称为**堆栈调和（Stack Reconciliation）**，这种方法一旦开始就不能中断，直到整个组件树都被遍历完。这种机制在处理大量数据或复杂视图时可能导致主线程被阻塞，从而使应用无法及时响应用户的输入或其他高优先级任务。

- **Fiber**

  它将原有的同步渲染任务拆分成一系列可中断和可恢复的小块（被称为 fibers），允许React在渲染过程中适时暂停并返回控制权给浏览器，优先处理高优先级的任务，如处理用户交互或动画帧渲染，然后再继续执行剩余的渲染工作。
